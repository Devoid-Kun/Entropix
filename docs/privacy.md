# Privacy Policy — Entropix

Last updated: [08.31.2026]

Entropix ("the bot") is a Discord application that monitors a designated
text channel to calculate a real-time "chaos index" and posts a daily
activity digest.

## What we collect
- Discord user IDs and message timestamps, for the sole purpose of computing
  daily statistics (most active hour, top contributors, inactive members).
- Server (guild) configuration: target channel ID, admin channel ID,
  language preference, and custom channel-name presets.

## What we do NOT collect
- Message content is analyzed in memory to score the current "chaos level"
  and is never written to disk or stored in our database.

## Data retention
- Daily statistics are purged automatically every 24 hours.
- Server configuration is kept until the bot is removed from the server,
  at which point it is deleted.

## Data sharing
We do not sell, share, or transmit collected data to any third party.
